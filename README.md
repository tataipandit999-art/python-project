# Mobile Shop Management System

A simple **Python-based Mobile Shop Management System** that allows users to manage mobile phone records through a menu-driven interface.

## Features
- **Add Mobile:** Add new mobile records.
- **Display Mobiles:** View all available mobile records.
- **Search Mobile:** Search by Mobile ID.
- **Update Mobile:** Modify existing mobile details.
- **Delete Mobile:** Remove mobile records.
- **Exit:** Close the application.

## Technologies Used
- Python
- Lists
- Functions
- Loops
- Conditional Statements
- Match-Case

## How to Run

1. Install Python 3.10 or above.
2. Download or clone this repository.
3. Open the project folder in VS Code or PyCharm.
4. Run the following command:

```bash
python mobile_shop_crud.py
```

## Note
This project uses Python lists for storing records temporarily. Data will be lost when the program is closed.
